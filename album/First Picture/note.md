# First Picture

这是一张留给网站初始阶段的照片。

我希望随笔区不只是把图片铺在页面上，而是让每一张图都带一点情绪、观察或者当时顺手记下来的想法。这样它才更像个人网站，而不是单纯的图库。

## 一点随笔

页面的背景、信息密度和浏览节奏，其实都会影响一张图被观看的方式。
如果背景本身已经很强，前景信息就更需要克制、有边界，而且要有一点呼吸感。
